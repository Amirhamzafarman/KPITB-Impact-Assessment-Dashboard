# KPITB Impact Assessment Dashboard

An interactive e-Governance impact assessment dashboard for Khyber Pakhtunkhwa (KPK), quantifying the financial, public, environmental, and governance transformations achieved through digitised public service delivery across all 43 districts.

---

## 🌟 Key Performance Indicators (Whole KPK Combined)

- **Total Public Transactions Processed**: **4,047,875** (~4.05 Million)
- **Documented Treasury Revenue**: **PKR 7,520,659,777** (~PKR 7.52 Billion)
- **Direct Citizen Out-of-Pocket Savings**: **PKR 10,122,257,000** (~PKR 10.12 Billion)
- **Working Hours Returned to Citizens**: **97,149,000 Hours** (~11.1 Million Working Days)
- **Physical Visits Avoided**: **8,095,750 Visits**
- **A4 Paper Sheets Preserved**: **12,143,625 Sheets**
- **Water Preserved**: **364,308,750 Liters**
- **Carbon Emissions Avoided**: **46,206.49 Metric Tons CO₂e**
- **Trees Saved**: **1,457 Trees**
- **Travel Distance Avoided**: **121,436,250 KM**

---

## 🛠️ Included Systems

1. **Arms & Licensing System (Home Department)**: 622,703 licenses processed | PKR 4.03 Billion revenue collected.
2. **Motor Vehicle Registration System (MVRS - Excise & Taxation Department)**: 3,425,172 transactions processed | PKR 3.49 Billion revenue collected.

---

## 🚀 Interactive Features

- **System Selector Tabs**: Toggle between `Whole KPK Combined Impact`, `Arms & Licensing`, and `MVRS`.
- **Live Dynamic Filters**: Datewise, Gender wise, Sub Service wise, Status, and District filters.
- **Visual Analytics**: Interactive Chart.js visualisations for service volume, yearly growth trends, top districts, and gender breakdowns.
- **District Impact Explorer**: Searchable and sortable performance table across all 43 districts in KPK.
- **Export & Print**: Integrated print styles for executive reporting.
